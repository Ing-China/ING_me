## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Commands

`astro` is a local dependency, not a global one, so invoke it as `npx astro …` (e.g. `npx astro dev --background`) or through the npm scripts:

- `npm run dev`: dev server at `localhost:4321`
- `npm run build`: static build to `./dist/`
- `npm run preview`: build, then serve `./dist/` through `wrangler dev` (the Cloudflare runtime, so `_headers` applies)
- `npm run deploy`: build, then `wrangler deploy` to Cloudflare
- `npm run astro -- <cmd>`: any other Astro CLI command (e.g. `astro add`, `astro check`)

There is no test runner, linter, or formatter configured yet. `astro check` (type-checking `.astro` files) prompts to install `@astrojs/check` the first time it runs.

Requires Node `>=22.12.0` (see `engines` in `package.json`).

## Architecture

A single-page personal portfolio (name, description, and an animated logo next to the name). Static output, no integrations or UI frameworks.

- `src/pages/index.astro`: the only page. Holds the content, the page-scoped styles, and the small script that rotates the logos.
- `src/layouts/Layout.astro`: the HTML shell and all SEO tags (canonical, Open Graph, Twitter card, theme-color, `Person` JSON-LD). Takes `title`, `description`, and optional `image` props. Absolute URLs are built from `site` in `astro.config.mjs` (`https://ingchina.dev`).
- `src/pages/robots.txt.ts`, `src/pages/sitemap.xml.ts`: static endpoints generated at build time from `site`.
- `src/styles/global.css`: `@font-face`, light/dark color variables on `:root`, reset, and `body` styles. Imported by the layout. The `Funnel Display Fallback` faces are Arial with `size-adjust`/`ascent-override` metrics tuned to match Funnel Display and avoid layout shift on font swap; retune them if the font or weights change.
- `src/assets/logos/*.svg`: brand logos (from Simple Icons) imported as Astro SVG components. Use `fill="currentColor"` for logos that should follow the theme.
- `public/og.png`, `favicon.png`, `favicon.ico`, `apple-touch-icon.png`: pre-rendered images with the name and description baked in. Regenerate them if the name or description changes.
- `public/fonts/`: self-hosted Funnel Display (Latin subset, variable weight 300–800), preloaded in the layout.
- `public/google*.html`: Google Search Console verification file. Keep it.
- TypeScript uses `astro/tsconfigs/strict`. Generated types live in `.astro/`, which is gitignored and regenerated by `astro dev`, `astro build`, or `astro sync`.

## Deployment

Hosted on Cloudflare Workers as static assets only (no worker script): `wrangler.jsonc` points `assets.directory` at `./dist`. `public/_headers` sets long-lived immutable caching for `/fonts/*` and `/_astro/*`, so give changed font files a new filename.
